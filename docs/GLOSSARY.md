# GLOSSARY

(PT-BR terms in brackets, for reference.)

- **ADR** — Architecture Decision Record. A written decision with context and trade-offs (`DECISIONS.md`).
- **Alignment (wall)** — Which side of the drawn line the wall's thickness sits on.
- **ART / RRT** — Brazilian registrations of technical responsibility (engineer: ART/CREA; architect: RRT/CAU).
- **Arching action** — Masonry above an opening partly carries itself like an arch, reducing the load on the lintel.
- **Bearing length** — How far a lintel/beam rests on its support at each end.
- **Bracing / shear wall** — A wall that resists horizontal (wind/earthquake) forces in its own plane.
- **Buckling** — Sudden sideways failure of a slender element under compression.
- **Characteristic vs design value** — Real expected value vs value with safety factors applied. Never mix them.
- **Command pattern** — Every edit is an object that can be done/undone. Basis of undo.
- **Dead load** [carga permanente] — Permanent weight.
- **Deflection** [flecha] — How much a beam/slab sags.
- **Finding** — A possible issue reported by a rule.
- **Fingerprint** — A stable identity for a finding, used to diff before/after an edit.
- **Handing** — Whether a door is left- or right-handed (which side the hinges are on).
- **Header** — A lintel in timber/steel framing.
- **Host (wall)** — The wall an opening belongs to.
- **Infill wall** [alvenaria de vedação] — A non-load-bearing wall filling a concrete frame.
- **Invariant** — A condition the model must always satisfy.
- **Lintel** [verga] — Small beam over an opening.
- **Sill reinforcement** [contraverga] — Reinforcement under a window opening in masonry.
- **Live load** [carga acidental / variável] — People, furniture.
- **Load path** — The route forces take to the ground.
- **Load takedown** — Adding up loads from top to bottom, storey by storey.
- **Pier** — The strip of wall between two openings, or between an opening and a wall end.
- **Profile** — A country code × construction system bundle of thresholds and default values.
- **Slenderness** — Height ÷ thickness (effective). High = buckling-prone.
- **Span / span direction** — Distance a slab/beam bridges, and the direction it bridges in.
- **Structural masonry** [alvenaria estrutural] — Masonry walls that carry the building's loads.
- **Tributary area** — The area of a floor whose load goes to a given support.
- **UDL** — Uniformly distributed load.
- **Utilization** — Demand ÷ capacity (e.g. 0.8 = 80% used).
